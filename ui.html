Google Drive

Connected

Notes live in the DriveNotes folder of your Drive as Google Docs. Edit them from the Google Docs app on your phone; changes appear here within ~30 seconds.

One-time setup (about 3 minutes). Google requires each personal app to have its own sign-in key.

How to get your Client ID & secret
  1. Open Google Cloud → New project, name it “DriveNotes”, Create.
  2. Enable the Google Drive API for that project.
  3. Open Google Auth Platform → Get started. App name “DriveNotes”, your email, Audience External, Create.
  4. Go to Audience → click Publish app (keeps you signed in; otherwise Google logs you out every 7 days).
  5. Go to Clients → Create client → type Desktop app → Create. Copy the Client ID and secret here.

When signing in, Google shows “Google hasn't verified this app” — that's your own app, so click Advanced → Go to DriveNotes.
